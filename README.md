# Tushar Patil — Java Developer Portfolio

Responsive animated portfolio made with plain HTML, CSS and JavaScript. No framework or build step is needed.

## Files
- `index.html` — page content and metadata
- `css/style.css` — responsive dark theme, animations, mobile navigation
- `js/main.js` — menu, scroll progress, reveal effects, copy-email, back-to-top
- `assets/favicon.svg` — custom TP favicon

## Preview
Open `index.html` in a browser. Google Fonts are loaded online; the page itself does not need a build process.

## Publish on GitHub Pages
1. Create a public repository.
2. Upload the contents of this folder to the repository root: `index.html`, `css/`, `js/`, `assets/`, and `README.md`. Do not upload only the ZIP.
3. Commit to `main`.
4. Go to Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
5. Wait for deployment and open the URL shown in Pages settings.

## Before sharing
- Replace the LinkedIn placeholder with your real profile URL.
- The hero portrait is an illustrated placeholder; replace it with your photo if you choose.
- Confirm each project description is accurate and share only work you're allowed to publish.
- The Resume/CV button currently opens an email request; link a PDF resume if you want direct download.
